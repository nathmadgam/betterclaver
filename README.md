# Better Claver

A community-run portal for **Claver, Surigao del Norte**: municipal officials, offices, services and public information in one place.

Better Claver is a volunteer project listed in the [BetterGov.ph LGU Directory](https://lgu.bettergov.ph/). It is **not** an official website of the Municipality of Claver.

## About Claver

Claver is a coastal municipality in the province of Surigao del Norte, Caraga Region, on the island of Mindanao facing the Philippine Sea. It is primarily a mining town with nickel and other mineral deposits, and a nickel ore loading port is located at Taganito. It has 14 barangays and a population of 36,033 (2020 Census).

## Run it locally

Requires Node.js 18 or newer.

```bash
npm install
npm run dev
```

Then open http://localhost:5173.

Site content lives in `content/` (Markdown and YAML) and `src/data/`. See [CONTENT-MANAGEMENT.md](CONTENT-MANAGEMENT.md) for how to edit pages without touching code.
